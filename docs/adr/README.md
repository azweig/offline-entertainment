# Architecture Decision Records

Short records of the decisions that shape this project, in the
[Michael Nygard format](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions).
To change one, add a new ADR that supersedes it.

| # | Decision | Status |
|---|---|---|
| [0001](0001-single-file-stdlib-server.md) | One Python file using only the standard library | Accepted |
| [0002](0002-library-lives-on-the-phone.md) | The library lives on the phone; the server is a pass-through | Accepted |
| [0003](0003-extractor-allowlist-and-dns-guard.md) | Closed site allowlist, exact extractors and a DNS guard | Accepted |
| [0004](0004-mandatory-key-in-url-fragment.md) | A key is always required, handed over in the URL fragment | Accepted |
| [0005](0005-no-accounts-cookies-or-evasion.md) | No accounts, cookies, proxies or block evasion | Accepted |
| [0006](0006-resumable-downloads.md) | Resumable downloads | Accepted |
